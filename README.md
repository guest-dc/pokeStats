# Poke-Stats

Davis Guest  
Mercer University  
CSC 499 Research Project

## Abstract

This project presents the design and development of a web-based application that calculates and displays battle performance metrics for all available Pokémon in Pokémon GO. Built entirely with static assets and deployed via GitHub Pages, the app emphasizes speed, transparency, and usability. Core data is sourced from a parsed Game Master API and enriched with custom release and shadow availability data derived from web scraping public wikis. Using clearly defined formulas for Damage per Second (DPS) and Total Damage Output (TDO), the tool enables players to explore top-performing movesets with client-side filtering and no external dependencies. The application matches existing tools in accuracy while offering full visibility into its calculations, addressing a common lack of transparency in community resources. Performance testing and informal user feedback affirm the app’s effectiveness, with future improvements aimed at expanding documentation and visual presentation.
